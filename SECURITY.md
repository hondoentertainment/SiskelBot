# Security Policy

## Supported versions
The latest minor version on the `main` branch is supported.

## Reporting a vulnerability
**Do not open public issues for security vulnerabilities.**

Email security@hondoentertainment.com with:
- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Suggested fix (if any)

We will acknowledge within 48 hours and provide an estimated timeline for fix and disclosure.

## Disclosure policy
We follow coordinated disclosure. Please give us 90 days from initial report before public disclosure.
